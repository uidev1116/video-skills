# video-skills 設計概要

## プロジェクトの目的

Claude Code エージェントが動画編集タスクを自律実行できるようにするプラグイン。
動画コンテンツを作る開発者・エンジニアが対象。

## 主要ユースケース

- スクリーンキャスト・チュートリアル動画の自動編集（無音カット・言い直しカット）
- 背景ノイズ・環境音の除去
- 字幕（SRT）の自動生成
- カット編集 → ノイズ除去 → 字幕生成 → 書き出しの一括パイプライン

## スキル構成

| スキル | 役割 | 主な依存 |
|--------|------|---------|
| `ffmpeg-edit` | 動画カット・結合・トランスコード・メタデータ取得 | FFmpeg |
| `whisper-caption` | Whisper による文字起こし・SRT/VTT 生成 | faster-whisper |
| `noise-clean` | 背景ノイズ除去・音声クリーニング | noisereduce / Demucs |
| `video-pipeline` | 上記3つを束ねるオーケストレーター | -- |

### 外部連携（別途インストール）

- `remotion-best-practices` -- アニメーション字幕が必要な場合
- `elevenlabs-tts` -- ナレーション生成が必要な場合

## 設計原則

1. **Claude Code が bash コマンドをそのままコピペして実行できる**形で書く
2. **M4 Mac を第一ターゲット**とするが、Linux でも動くことを確認する
3. **スキルを使わなくても読めば理解できる**ドキュメントにする
4. **Progressive Disclosure**: SKILL.md 本体は短く、詳細は references/ に分離
5. **失敗パターンと回避策を必ず書く**（エラーハンドリング重視）

## 必要な環境

- FFmpeg 4.0 以上
- Python 3.9 以上
- pip（Python パッケージ管理）
